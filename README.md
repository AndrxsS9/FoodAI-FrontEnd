# FoodAI — Frontend

Cross-platform mobile application (Android & iOS) that analyzes food ingredients from images and recommends recipes based on available ingredients, budget, and household preferences.

## Tech Stack
- React Native
- Expo
- TypeScript
- Expo Router

## Branching Model
- `main`: Protected final-production branch.
- `develop`: Primary integration and active development branch.
- `feature/*`: Dedicated branches for features and components.
